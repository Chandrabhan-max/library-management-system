# 📚 Library Management System

A modern Library Management System frontend built with **React** and **Vite**.  
This application provides an intuitive interface for browsing books, managing borrowing activities, and administering library operations.

---

## ✨ Features

- Browse books by genre
- View available resources
- User profile management
- Admin control panel
- Borrowed books tracking
- Clean, responsive UI with animations

---

## 🛠️ Tech Stack

**Frontend**
- React
- Vite
- Framer Motion
- CSS (custom styling)
